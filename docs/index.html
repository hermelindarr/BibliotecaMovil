Las 7 Actividades de Diseño en .NET MAUI 10

Implementación detallada de cada contenedor de diseño según la guía oficial y el laboratorio práctico de 60 minutos.

1
Linear Vertical

StackLayout & VerticalStackLayout

Organiza los controles en una sola dirección vertical. Ideal para formularios, pantallas de inicio de sesión y secuencias lineales.

Uso en la app: Views/LoginPage.xaml (Logo, título, inputs de usuario y contraseña, y botón de inicio). 
<VerticalStackLayout Spacing="12" Padding="20">
    <Label Text="Usuario" />
    <Entry Placeholder="admin" />
    <Label Text="Contraseña" />
    <Entry IsPassword="True" />
    <Button Text="Iniciar sesión" />
</VerticalStackLayout>
2
Linear Horizontal

HorizontalStackLayout

Distribuye los controles en una sola fila horizontal con espaciado constante. Perfecto para barras de acciones y botones con iconos.

Uso en la app: Views/CatalogoPage.xaml (Barra de botones "+ Nuevo libro", "Lista/Cuadrícula" y contador). 
<HorizontalStackLayout Spacing="10">
    <Button Text="+ Nuevo libro" Style="{StaticResource BtnExito}" />
    <Button Text="Lista" Style="{StaticResource BtnContorno}" />
    <Label Text="13 libros" VerticalOptions="Center" />
</HorizontalStackLayout>
3
Cuadrícula Flexible

Grid

El contenedor más potente: organiza elementos en filas y columnas proporcionales (*), automáticas (Auto) o de tamaño fijo.

Uso en la app: Views/LibroFormPage.xaml y resumen de inicio ColumnDefinitions="*,*,*". 
<Grid RowDefinitions="Auto,Auto,*" ColumnDefinitions="Auto,*" ColumnSpacing="12">
    <Label Text="Título:" Grid.Row="0" Grid.Column="0" />
    <Entry Grid.Row="0" Grid.Column="1" />
    <Label Text="Autor:" Grid.Row="1" Grid.Column="0" />
    <Entry Grid.Row="1" Grid.Column="1" />
</Grid>
4
Flujo & Envoltura

FlexLayout

Distribuye controles con soporte para salto de línea (Wrap="Wrap"), alineación flexible y distribución de espacio sobrante.

Uso en la app: Views/CatalogoPage.xaml (Chips de categorías adaptables a cualquier ancho de pantalla). 
<FlexLayout Direction="Row" Wrap="Wrap" JustifyContent="Start" AlignItems="Center">
    <!-- Chips generados dinámicamente -->
    <Border Style="{StaticResource Chip}">
        <Label Text="Programación" />
    </Border>
</FlexLayout>
5
Posicionamiento Libre

AbsoluteLayout

Posicionamiento libre exacto o proporcional mediante coordenadas (X, Y, Ancho, Alto) y superposición visual de capas.

Uso en la app: Views/LoginPage.xaml (fondo con gradiente y formas) y portada con insignias "Nuevo" y "Disponible". 
<AbsoluteLayout>
    <Image Source="portada.png" AbsoluteLayout.LayoutBounds="0,0,1,1" AbsoluteLayout.LayoutFlags="All" />
    <Label Text="NUEVO" AbsoluteLayout.LayoutBounds="8,8,60,24" BackgroundColor="Orange" />
</AbsoluteLayout>
6
Colecciones Dinámicas

BindableLayout

Genera controles a partir de una colección sin la sobrecarga de un CollectionView. Recomendado para listas pequeñas y chips.

Uso en la app: Generación de categorías en CatalogoPage.xaml y autores destacados en InicioPage.xaml. 
<FlexLayout BindableLayout.ItemsSource="{Binding Categorias}">
    <BindableLayout.ItemTemplate>
        <DataTemplate>
            <Border Style="{StaticResource Chip}">
                <Label Text="{Binding Nombre}" />
            </Border>
        </DataTemplate>
    </BindableLayout.ItemTemplate>
</FlexLayout>
7
Diseño Personalizado + Estilos

Custom Layout: MosaicoLayout & Estilos Globales

Creación de un layout propio en C# heredando de Layout e implementando ILayoutManager con algoritmos propios de Measure y ArrangeChildren. Alterna celdas destacadas a lo ancho con celdas compactas. Además, recursos centralizados en Colors.xaml y Styles.xaml.

Uso en la app: Controls/MosaicoLayout.cs para los accesos rápidos de InicioPage.xaml. 
public class MosaicoLayout : Layout {
    protected override ILayoutManager CreateLayoutManager() => new MosaicoLayoutManager(this);
}
public class MosaicoLayoutManager(MosaicoLayout layout) : ILayoutManager {
    public Size Measure(double widthConstraint, double heightConstraint) { /* calcula alto dinámico */ }
    public Size ArrangeChildren(Rect bounds) { /* posiciona celdas destacadas y secundarias */ }
}
Persistencia y Acceso a Datos

Arquitectura de Datos y Patrón DAO

Diseño robusto con SQLite local, ORM sqlite-net-pcl, consultas optimizadas y control de transacciones.

🗄️

Base de Datos SQLite

Archivo biblioteca.db3 ubicado en el almacenamiento privado de la app. Incluye tablas para Libros, Usuarios y Préstamos con claves primarias autoincrementales y foráneas.

🧩

Patrón DAO

Desacoplamiento total mediante interfaces (ILibroDAO, IPrestamoDAO, IUsuarioDAO). Las vistas no interactúan con SQLite, solo con los contratos DAO inyectados por DI.

⚡

Consultas Optimizadas

Uso de CREATE INDEX idx_prestamos_activos en (FechaDevolucion, FechaLimite), consultas parametrizadas anti-SQLi y proyecciones selectivas de columnas.

🔐

Seguridad y Transacciones

Contraseñas protegidas mediante PBKDF2-SHA256 con sal criptográfica aleatoria. Operaciones de préstamo y devolución ejecutadas bajo transacciones atómicas (RunInTransactionAsync).

Cómo Ejecutar la Aplicación .NET MAUI

Instrucciones paso a paso para compilar y ejecutar el proyecto en Windows o en el emulador de Android.

  1. Clona el repositorio o descarga el archivo ZIP: 
    git clone https://github.com/hermelindarr/BibliotecaMovil.git
  2. Abre la carpeta en Visual Studio 2026 (o Visual Studio 2022 v17.10+) con la carga de trabajo .NET Multi-platform App UI development.
  3. Selecciona como proyecto de inicio BibliotecaMovil.csproj.
  4. Elige tu destino de depuración: Windows Machine o un Emulador Android (Pixel / API 34).
  5. Presiona F5 para compilar y ejecutar.
